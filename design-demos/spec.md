# 退休规划 · 手机向导版 — 设计 spec（三方向共同输入）

## 项目
基于 `retirement_v2.html` 的计算模型（BGN 模式三阶段 TVM），做一个客户自用的手机网页向导。
单个 HTML 文件，静态托管，用链接 / 二维码传播；微信内置浏览器、Safari、Chrome 都能用。

## 受众与场景
- 顾问 Yang Yang（GEFA）的客户及其转发对象，主要是新加坡华人，35–60 岁
- 受过良好教育，但金融知识有限；中文阅读为主，可切换英文
- 场景：自己在手机上点开，5 分钟内走完，看到结果后可以一键 WhatsApp 联系顾问

## 核心信息（每一屏要讲清的事）
1. 按今天的生活标准，退休时每月要花多少（通胀后）
2. 退休那天需要准备多少资本
3. 现有储蓄能覆盖多少，还差多少
4. 从今天起每月需要投资多少，投资多少年
5. 资产余额的完整历程：积累 → 退休 → 计划结束时归零
6. 所有数字基于假设，不是保证

## 流程（9 步，可从进度条和结果页"修改"跳回任一步）
性别 → 当前年龄 → 退休年龄 → 退休年数 → 现有储蓄 → 生活档次/月开支 → 假设（保守/平衡/进取预设 + 高级调整）→ 结果 → 两种策略对照

## 情感基调
可信、安静、对"老了以后"的话题有温度但不煽情；不制造焦虑，不推销。

## 输出格式与尺寸（三版统一）
- 展示板 1440 宽；每个方向两屏：**输入步骤（第 6 步：生活档次）** + **结果页**
- 每屏 390 × 844（手机网页视口），屏内文字为真实尺寸
- 不画 iPhone 外壳和状态栏（这是网页，不是原生 App），屏幕用圆角矩形表示
