# 六张方向卡

## A · 最佳设计师｜Giorgia Lupi（Pentagram，Data Humanism）
- 借的：把个人数据画成"人生肖像"，不是图表；一个点 = 一年；颜色编码阶段；手绘感图例
- 主角素材：人生年历点阵：40→85 岁，46 个点，供款绿、退休珊瑚，点的大小代表当年资产
- 骨架：顶部一句话结论 → 中间点阵占半屏 → 下方 3 个关键数字 → 底部联系栏
- 胆量：结果页首屏不放大数字，放"你的 46 年"点阵
- form：退休规划就是一段年龄，一年一个点，题材本身自带的单位

## B · 最佳设计师｜吕敬人（书籍设计）
- 借的：书页结构、竖排小标题、天头地脚留白、一枚朱印做唯一的强调
- 主角素材：宋体巨字数字 + 竖排章节名
- 骨架：左侧竖排章名条，右侧正文栏；结果页像一页"退休规划书"
- 胆量：总资本需求用宋体巨字占据一页上半
- form：一份写给自己的退休规划书，翻页对应向导的步骤

## C · 现实参照｜Monzo（友好金融，样张 app/04；原作未截图，借样张）
- 借的：顶部满版品牌色放主数字、白色抽屉面板抬起、34px 大圆角、胶囊按钮、口语化小标题
- 主角素材：巨字数字 + 圆角"罐子"色块
- 骨架：上 40% 色区 + 下方抽屉卡片
- 胆量：主色满版铺顶，换成新加坡语境的深海蓝绿 + 芒果黄
- form：钱分成几个"罐子"：已有的、还差的、每月要放的

## D · 现实参照｜Things 3（原生精修，样张 app/10；原作未截图，借样张）
- 借的：纯白纸感、单一蓝强调、缩进发丝线、浮起卡片
- 主角素材：列表与一张浮起的结果卡
- 骨架：步骤列表式
- 胆量：几乎没有，靠精修
- form：一步一勾，像清单

## E · 秒数轮盘（S=38）｜App #3 玩味 3D 材质（Not Boring 式）
- 借的：满版饱和主色、有厚度的按钮、一屏一个巨大主角（温度计式"资本进度管"）
- 主角素材：凸起的资本进度管
- 骨架：一屏一个主角，元素围绕
- 胆量：整屏酸绿 / 薰衣草
- form：资本像往管子里蓄水

## F · 秒数轮盘（S=38）｜East #3 民国书衣
- 借的：灰绿纸色、白题签条竖排书名、细双线框、平涂几何山日
- 主角素材：题签 + 几何"日落山"图形
- 骨架：书衣式封面 + 内页
- 胆量：结果页做成书衣
- form：晚年即"夕阳"，但容易用力过头

## 挑选（4d）
做完整版：**A（Lupi 点阵）→ dir-1 方向 A · C（友好金融）→ dir-2 方向 B · B（吕敬人书页）→ dir-3 方向 C**
- 三者骨架不同（点阵叙事 / 色区 + 抽屉 / 书页竖排），温度不同（中性 / 大胆 / 安静）
- D 太接近通用模板，作为备选；E 的高饱和对 50+ 客户谈退休金偏轻佻，作为备选；F 把整页做成道具，去掉手法信息更清楚，判定过头，作为备选
