📐 计算流程（按 Step 顺序）

① Future Value of Desired Monthly Expense

把客户输入的「今日月开销」逐段通胀到 decumulation 起始点

monthly_at_decum = desired_monthly_today
  × (1 + i_pre) ^ years_pre
  × (1 + i_wait) ^ years_wait  // 若等待期关闭则 years_wait = 0

annual_at_decum = monthly_at_decum × 12

② Lump Sum Needed @ Start of Decumulation

支付 N 年逐年抗通胀提取所需的本金（生长年金 PV，期初提取，余额按 r_post 复利）

// r ≠ i 时:
LS = annual_at_decum × [1 − ((1 + i_post)/(1 + r_post))^N] / (r_post − i_post)

// r = i 退化为:
LS = annual_at_decum × N / (1 + r_post)

N = years_retired；与 Excel UT-FI-10 row 24 的 H 列递推公式严格一致（B_N = 0 边界）

③ Monthly Savings Required (From Now)

已有储蓄复利增长 + 月供累积 → 累积到 LS（折回到退休时点）

target_at_retirement = LS / (1 + r_wait) ^ years_wait
ES_at_retirement = existing_savings × (1 + r_pre) ^ years_pre
shortfall = target_at_retirement − ES_at_retirement

m_pre = (1 + r_pre)^(1/12) − 1  // 月化利率
M = years_pre × 12

monthly_savings = shortfall / [((1 + m_pre)^M − 1) / m_pre]

④ Capital Preservation Model

每年只取本金产生的股息，本金恒定

annual_income_CP = LS × yield_cp
monthly_income_CP = annual_income_CP / 12
capital_CP(t) = LS  // 任意年份恒为 LS

real_value_at_year_t = annual_income_CP / (1 + i_post)^t  // 用于"今日购买力"显示

⑤ Capital Drawdown Model（与您 Excel UT-FI-10 一致）

年初提取，剩余按 r_post 增长；提取额每年按 i_post 上涨

W_1 = LS × withdrawal_cd  // 用户可调；默认 4%
W_t = W_1 × (1 + i_post) ^ (t − 1)
B_0 = LS
B_t = (B_{t-1} − W_t) × (1 + r_post)  // 余额递推

depletion_year = min{ t : B_t ≤ 0 }  // 耗尽年份，可能 > years_retired 表示有盈余

🛠 技术结构

文件结构

Calculator/
├── retirement.html  # 主文件 (50–80KB)

└── docs/superpowers/specs/
    └── 2026-05-25-retirement-
        calculator-design.md

单文件 HTML，内联 CSS + 内联 JS，双击即开

技术栈

  • HTML5 + Vanilla JS（ES2020+）
  • CSS：内联，CSS Grid + Flexbox
  • Chart.js v4（CDN 引入，~70KB）
    用于资产余额图 + 取款额图
  • 无构建步骤、无后端、无数据上传
  • 支持浏览器 Print → Save as PDF（@media print 优化版面）

状态管理

  • 单一全局 state 对象（所有输入字段）
  • 任意输入变化 → 触发 recalculate() → 重渲染所有派生数
  • Step 3 的滑块响应 input 事件 → 实时更新（无需"Calculate"按钮）

验证 / 边界

  • 退休年龄必须 ≥ 现年龄 + 1
  • 所有 %、年龄、金额 ≥ 0
  • r = i 时退化公式自动切换
  • 计算总额 ≤ JS Number.MAX_SAFE_INTEGER（足够覆盖任何合理场景）
  • Capital Drawdown 提前耗尽时，图表延伸到耗尽年并标红
