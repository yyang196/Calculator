三阶段时间轴：等待期的语义？

请确认每个阶段的起止点与所用利率/通胀

① ACCUMULATION（退休前累积期）

现年 → 退休年龄
在职、月供入退休账户，资金按 pre-retirement return 复利增长；目标月开销按 pre-retirement inflation 上涨
📈 pre return  ·  📊 pre inflation

② WAITING（等待期）

退休年龄 → 开始提取
已退休但暂不提取，资金继续增长。常见于客户希望让本金多滚几年再领
❓ 用哪一组利率/通胀？

③ DECUMULATION（取款期）

开始提取 → 终老
每月/每年提取资金作生活费；资金按 post return 增长，开销按 post inflation 上涨
📈 post return  ·  📊 post inflation

请确认：等待期阶段的资金行为？

A

沿用 pre-retirement 利率与通胀

等待期视为「累积期的延长」——人虽然退休了，但钱还在原有投资组合里继续按 pre return 增长，没有人为切换

B

沿用 post-retirement 利率与通胀

等待期视为「取款期的前置」——客户在退休时点就已经把组合切到更保守，只是先不取钱让它滚利

C

等待期单独设第三组利率/通胀

给顾问最大灵活度——可以模拟「过渡期」介于 pre/post 之间的稳健组合，但 UI 上要多两个输入框
